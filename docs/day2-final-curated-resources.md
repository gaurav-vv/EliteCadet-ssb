Selection followed: prefer verified over unverified, free over paid where quality is comparable, no-login over login-required where quality is comparable, realistic/automatic timing, multiple sets/test series, large practice banks, and resources a student can use immediately. Generic SEO articles, unverifiable platforms, and flagged/abandoned resources were excluded. No resource is ranked as "best." No TAT pictures, WAT words, SRT situations, SD samples, or paid content are reproduced anywhere below — only links and metadata.

## Recommended EliteCadet Resource Structure

*Evidence-based organization proposal only — not implemented, no product decision made.*

Based purely on what the curated resources actually are, they would map onto these functional groups:

**Practice** (untimed or self-paced picture/word/situation exposure)
→ SSB Arena, Cavalier TAT pictures, Troppers (TAT/WAT/SRT sets)

**Timed Tests** (single-session, automatic-timer tools per test)
→ DOSPDP (TAT/WAT/SRT), Target SSB app (TAT/WAT/SRT), SSB Practice (TAT/WAT/SRT/SD), WishWas (TAT/WAT/SRT/SD), SSB Buddy (WAT/SRT)

**Test Series** (resources with multiple, distinct, verified sets)
→ ssbpsychtest.in (50+/25/25/1 sets — by far the largest banks), Troppers (20/10/10 sets), SSB Buddy Android app (200+/450+/120+ claimed), DOSPDP (5 WAT sets, 2 SRT sets)

**Full Mock** (complete TAT→WAT→SRT→SD sequence)
→ ssbpsychtest.in's Full Mock mode (the only one confirmed); SSB Smart Learning App and Provers as partial/broader-but-less-verified alternatives

**Learn** (curated explainers)
→ The 13 articles in §6, grouped by test

**Expert Demonstrations** (named/credentialed video content)
→ Maj Gen VPS Bhakuni (TAT), Ashok Kumar Thamburaj (SRT/Full Day 2), Gp Capt AK Srivastava (Full Day 2 channel), Major Kalshi Classes (Full Day 2 live session)

**Feedback** (kept structurally separate — Human vs. AI, with AI never presented without its confidence caveat)
→ Human: AFPA, SSB Psych Prep, ClearSSB (paid), NCA free trial (free, one-time)
→ AI: Provers as the least-unverified option, all others carrying explicit LOW/VERY LOW confidence labels

A student's natural path through this structure would follow the Learn → Example → Practice → Timed Practice → Test Series → Full Mock → Feedback → Improve loop from the original brief, with SD/SDT explicitly flagged in the UI as a thinner section (3 practice resources vs. 7–9 for the other three tests) so students aren't left assuming parity that doesn't exist in the external ecosystem.
