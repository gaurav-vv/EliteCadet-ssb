# SSB Academy — Web Platform

Next.js (App Router) + TypeScript + Tailwind CSS web platform for SSB preparation, serving Student,
Mentor and Academy Admin roles.

## Project governance

This repository is governed by four files. Read them in this order before making any change:

1. [`specs.md`](./specs.md) — what the product must do
2. [`AGENTS.md`](./AGENTS.md) — how to build it (architecture, conventions, design system)
3. [`task.md`](./task.md) — implementation roadmap and task status
4. [`status.md`](./status.md) — current, verified state of the repository

## Development

```bash
npm install
npm run dev      # start dev server at http://localhost:3000
npm run lint
npm run build
```
